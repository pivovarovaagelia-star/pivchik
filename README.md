# Пивчик

Новая клиентская основа каталога фильмов, сериалов и аниме на React + Vite.

## Запуск в Windows PowerShell

```powershell
npm.cmd install
npm.cmd run dev
```

Сборка:

```powershell
npm.cmd run build
```

## Каталоги и видео

- Карточки, поиск, фильтры, избранное и история работают в интерфейсе.
- Поиск аниме использует публичный каталог AniList; поиск поддерживает русские и английские названия, включая «Чёрный клевер» / Black Clover.
- Для расширенного каталога фильмов и сериалов можно добавить TMDB API Read Access Token в настройках. TMDB предоставляет метаданные и постеры, не видеопотоки.
- Плеер умеет подключать MP4/HLS, когда у проекта есть URL потока от поставщика, разрешающего воспроизведение и встраивание. В текущей версии лицензированный поставщик не подключён, поэтому кнопка «Смотреть» показывает честное уведомление, а не случайный или тестовый ролик.
- Регистрация, Premium-платежи и защищённая панель владельца требуют серверной части и платёжной интеграции; пока это не реализовано.
