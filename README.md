# Пивчик

Клиентская основа каталога фильмов, сериалов и аниме на React + Vite, оформленная по приложенному референсу.

## Скачать ZIP

ZIP с исходниками можно скачать через GitHub: [Download ZIP](https://github.com/pivovarovaagelia-star/pivchik/archive/refs/heads/main.zip). Это архив исходного кода, не готовая production-сборка.

## Запуск в Windows PowerShell

Открой PowerShell в распакованной папке проекта и выполняй по одной команде:

```powershell
npm.cmd install
npm.cmd run dev
```

Сборка для размещения:

```powershell
npm.cmd run build
```

После успешной сборки статические файлы появятся в `dist`. Предпросмотр production-сборки:

```powershell
npm.cmd run preview
```

## Что реализовано в клиентской основе

- Страница каталога с категориями, фильтрами, поиском, избранным и историей в текущем браузере.
- Аниме-метаданные из AniList; локальная карточка Black Clover помогает найти «Чёрный клевер» / «Черный клевер» / Black Clover.
- Фильмы и сериалы из TMDB после ввода Read Access Token в настройках; TMDB предоставляет метаданные и постеры, не видеопотоки.
- Ленивое декодирование изображений и адаптивная раскладка.
- Плеерная оболочка с поддержкой MP4/HLS URL, когда добавлен разрешённый поставщик.

## Что ещё не готово

Это пока не законченный онлайн-кинотеатр: лицензированный поставщик видео, подтверждённые видеопотоки, русские аудиодорожки и реальное воспроизведение не подключены. Не используйте посторонние/пиратские источники или случайные URL. Аккаунты, платёжный Premium и защищённая панель владельца требуют серверной части, безопасного хранения секретов и интеграции с платёжным провайдером; они не реализованы.

**Не помещайте TMDB-токен в исходники или ZIP.** Ключ, присланный в переписку, рекомендуется отозвать и заменить. Для личного теста токен можно ввести в настройках браузера, но этот способ не подходит для production-секретов. Подробности — в [SECURITY.md](SECURITY.md).

## Проверка

В текущей среде я не выполнял установку зависимостей или `npm run build`, поэтому ZIP исходников нельзя считать проверенной production-сборкой. Перед публикацией запустите команды сборки и проверьте сайт в браузере.
