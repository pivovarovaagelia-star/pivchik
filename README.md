# Пивчик

Клиентская основа каталога фильмов, сериалов и аниме на React + Vite. Визуальный стиль обновлён по приложенному референсу: космически-сказочный синий фон, фиолетовые панели, облачный баннер, кружка-маскот и горизонтальные карточки.


## Статус видео и источников

AniList и TMDB предоставляют каталожные метаданные и изображения, но не права на проигрывание фильмов или сериалов. Встроенный плеер не содержит лицензионного видеокаталога. Демонстрационные ролики нельзя считать фильмами; карточки каталога не должны подменяться тестовым видео.

Публичные каталоги Watchmode, JustWatch и TMDB могут помогать выяснять легальную доступность и перенаправлять зрителя к стримингу, но не дают права встраивать полные фильмы. Для прямого воспроизведения нужны права и коммерческий договор с поставщиком, который выдаёт разрешённые для стороннего сайта потоки и данные о русских аудиодорожках. Инфраструктурные платформы HLS/VOD подходят для собственного или лицензированного контента, который владелец сайта имеет право загружать.

Premium, платежи, пользовательские аккаунты и панель владельца требуют серверной части и интеграций; они не реализованы в текущей фронтенд-основе.

## Безопасность API-ключа

Не включайте TMDB-токен в исходники или ZIP. Токен, который уже был опубликован в переписке, следует отозвать и заменить. Для публичного сайта запросы и секреты должны обслуживаться сервером, а не клиентским браузером.

## Проверка

В текущей среде не запускались установка зависимостей, production-сборка или браузерные тесты. Проверьте проект локально перед публикацией. Не считать сайт законченным кинотеатром, пока не проверены сборка, запуск и лицензированные видеопотоки.
